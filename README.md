## Project Features

- **Workout Split Selector:** Plan workouts by specific training splits: Push Day (Chest/Triceps), Pull Day (Back/Biceps), Leg Day (Quads/Hamstrings), and Full Body.
- **Weekly Routine Planner:** Add, schedule, and filter routines by day with native HTML5 Drag & Drop row reordering.
- **Exercise Catalog:** Interactive exercise catalog with movement illustrations, equipment requirements, form cues, and muscle group tags (Chest, Back, Legs, Shoulders, Arms, Full Body).
- **Interactive Workout Logger:** Record daily sets, reps, and weights with dual unit support (`kg` and `lbs`) and automated volume calculation.
- **Rest Timer Between Sets:** Configurable countdown intervals (60s, 90s, 120s) with an audible completion chime synthesized via the Web Audio API.
- **Workout Session Stopwatch:** Measure total workout duration with split lap times.
- **Dashboard & Analytics:** Live summary statistics for planned routines, logged exercises, total volume lifted, and total time exercised.
- **Data Persistence & Export:** Full offline storage via browser `localStorage` and one-click JSON backup export.
- **Dark / Light Theme Toggle:** Customizable appearance with persistent theme settings.
- **Responsive & Print-Ready:** Responsive layout across all devices with clean print styling.
