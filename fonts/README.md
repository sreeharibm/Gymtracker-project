# Fonts Directory

Place your custom Astralaga font files here:

- `Astralaga-Regular.woff2` (or `.woff` / `.ttf`)
- `Astralaga-Bold.woff2` (or `.woff` / `.ttf`)

If no local font files are added, the project will automatically fall back to **Cormorant Garamond** and **Playfair Display** (high-contrast display serifs loaded via Google Fonts).
